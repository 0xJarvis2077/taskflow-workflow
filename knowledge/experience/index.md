# 公开经验笔记索引

这里保留专业出题、材料质检、独立自测、全卷复盘和返修的方法知识。S001—S016 沿用原有来源编号和文件名，便于方法文档引用迁移；每份为重新组织的公开经验笔记，不是第三方原文、逐字稿或原题资料。

公开笔记不包含具体题面、业务附件、标准答案、数值结果、真实模型成绩、私人会议链接或聊天身份。原有阅读范围和缺证限制仍逐篇保留；本次整理没有重新访问原站点，也没有开展真实模型实验。不能因笔记完整或可读，就宣称对应方法已经在某配置下达到难度目标或通过平台。

## 使用顺序

先用[规则快照说明](../policy-notes/README.md)确认当前项目和权限，再按问题选择来源。执行时从 [工作方法](../../docs/workflow-methods.md) 与 [协作架构](../../docs/task-collaboration-architecture.md)进入，避免把经验全文发给正式作答者或首阶段事实评阅者。

学习方法与正式题包分开：来源笔记不补造缺失原件，经验建议不自动成为评分义务；只有实际公开输入、已冻结标准和真实交付，才能支撑某一题的判定。
