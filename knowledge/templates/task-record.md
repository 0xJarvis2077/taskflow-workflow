# 题目工作记录模板

本模板是内部研发记录约定，不是平台提交格式。建立具体任务时复制到本地工作目录，按实际阶段填写；未知值保留“未提供／未运行”，不要编造。本记录及来源、设计和过程证据仅供内部研发，不导出为题面、业务附件或拟交付声明。字段对应的机器契约见[单题契约](../../docs/task-contract.md)。

## 身份和来源

- 题目 ID / 名称 / 版本：
- 适用项目、批次、期次、渠道与当前规则版本：
- 业务背景、领域依据及内部证据索引：
- 专家本人行业 / 职业（含当期表格字段名称与口径）：
- 任务业务领域 / 类型 / 交付对象 / 使用目的：
- 题干赋予模型的角色（若有，与专家身份分开）：
- 原始资料与处理／变换记录（仅内部追溯）：
- 数据处理依据、执行方式及跨文件一致性核验：
- 需联网检索的公开资料名称、网站/范围、版本与可获取性：
- 本批角色模型选择、用户确认来源与作用范围；未确定角色、实际载体及后续变更（按[协作架构](../../docs/task-collaboration-architecture.md)，不从历史配置补值）：

对重要难点按[S010第四节与第6.4节](../experience/S010-difficulty-methods.md)补充：顺手错法及可观察后果、正常对照结果、各业务因素如何影响判断、下游依赖与独立/传播错误。记录真实依赖，不强制每个考点达到固定因素数；无需重复制作已有信息。

重要增难改动可在以上难点记录中补充或引用已有底稿：上轮实际成功路径/新题教师试解 → 选用方法与来源 → 具体业务关系、输入及材料位置变化 → 正确结果、合理错法/反事实和正常分支 → 必须完成的主交付与对应验收。注明本来需由作答者完成的整理判断是否仍保留；没有真实运行时标为设计假设，纯质量纠错不强填增难关系。

## 本质质检

- 委托范围与总体目标：单轮审查 / 指定修复 / 持续研发；本轮用途及验收依据、已授权运行/服务/支出和预算边界（本地目标与平台规则分开）：
- 总体目标当前状态与证据；本轮结果结束的是某问题、候选/实验还是整项委托：
- 材料质量：业务价值、公开充分性、参考与验收是否成立；另列实际公开原件的判断归属结论，二者各引证据，不能用算对/评分公平代替剩余责任核验：
- 难度假设与证据：待测关系、实测支持/反证及尚未覆盖范围：
- 完整业务责任中由上游/材料/工具已完成的部分，仍由作答者承担的核心判断与实际结果：
- 最相关参照：历史通过 / 结构借鉴 / 当前配置实测；可比性及局限：
- 当前研发决定：补业务依据 / 对照或诊断 / 完整任务设计或验证 / 修质量 / 制作 / 结束当前候选方向；与上方质量结论分开，引用旧成功方法、当前公开试解及剩余重要判断的实际证据，说明正确/错误如何改变下一决定（不能只写有新机制、QA passed或尚未测过）：
- 可解性与材料可访问性：
- 标答事实/计算核验：
- 模型可见材料整包复审：初稿后 / 本轮投测前 / 返修后 / 交付前；当前提示词、附件及全部工作表/其他可见内容的读取范围和版本；以下核心判断归属记录或已有同等证据的位置、同类问题及复检结论：
- 增难落实复审：整题设计与私有参考位置；从实际公开原句/字段和跨文件组合核出输入已做工作，再与作者声明对照；保留上游成果后，旧成功方法仍覆盖哪些主要责任、剩余判断如何共同改变主交付；正确/错法/正常分支的结果及局限（不设机制数或局部先错门槛，不因合法程序短法自动否决）：
- 原创及与同批/往期题的实质差异：
- 问题与关闭记录（引用已有报告即可）：问题及证据 → 实际改动文件/版本 → 原问题与正反对照回放 → 实际派工/接收采用证据 → 后续独立成果及是否复发；未取得的阶段标待验证，不采纳的发现说明依据：
- 当前执行者承接的下一动作、预期产物与验证；若未能执行，记录具体范围/资源/外部依赖、已尝试路径及恢复条件：
- 质量状态：可探索性压测 / 需修订 / 范围不符 / 证据不足（不替代上方研发投入决定）。

### 核心判断归属（教师侧，复用难点ID及已有证据）

按[整包复审](../methods/design-review.md#模型可见材料的整包复审)覆盖本轮宣称的核心判断，不按文件数或考点数量凑行；相同责任可合并，已有完整记录可直接引用。检查跨文件组合、已加工字段和全局保证，不只摘显眼提示。该表和复核原因不进入题面、业务附件或solver包。

| | | | | | | |

处置说明实际采用“移出可移出的代做判断内容 / 保留正常上游成果并缩小能力声明 / 补原件在新版恢复判断 / 继续补证”等哪一种及其依据；保留修改前后原句/字段位置、必要条件和关联成果复检。不可只写“属于合法制度，所以无泄题”，也不因字段整齐、有公式或必要提醒重复一律删掉。若没有原件支持删除某项保证、权限或口径，不将其改成未知来制造难度。公示固定算法可测执行，但相应方法选择不能再算独立难点；移出一处预填方案后须复查其他文件是否仍给出同一方案。

- 本次审查所用输入版本及绑定 `input_digest` 的外部报告/manifest位置（不把包含本记录自身的摘要回填在此）：
- 公开独立推导者、实际可见范围、证据及局限；核算正确和判断未被代做分别结论：
- 业务审查关闭：关键责任是否仍与能力声明一致、必要条件是否完整、证据是否对应保存原件；未解决项为 `需修订/证据不足`，不填 `passed` 或直接正式投测。工具检查不自动验明本表语义：

初稿、返修和投测复检接续同一记录，变更保留前后依据。旧版本未做此审查时注明本次追溯复核，不补造事前结果，不据新方法追扣旧卷。
